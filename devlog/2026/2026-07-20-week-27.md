## Development Notes

The week opened with a dense kernel safety pass. Range comparison and mutation rules were tightened, delayed histories and async state transitions were corrected, and ComputeEngine parsing gained stricter structural validation. That same early stretch also hardened sockets, HTTP framing, XML ownership, timer and statistics behavior, and task scheduling, so the runtime surface became more defensive in several different directions at once rather than through one isolated subsystem.

Image and file handling then became a second major thread. JPEG and PNG support expanded on both input and output, decoder error handling and RGB conversion paths were tightened, and image metadata moved toward structured results. `OutputFile` also received a sustained series of changes around timestamps, numbering, delimiters, recording control, numeric formatting, JSON and JSON Lines output, and compatibility with `InputFile`, making file recording more explicit and less fragile by the end of the week.

Another concentrated block focused on operational reliability. Session logging removed local path leakage, moved onto verified HTTPS transport with bounded asynchronous delivery, and handled outages and metadata truncation more cleanly. At the same time, WebUI save and dialog handling were repaired so stale requests no longer corrupted Save As flows, broken startup models stayed editable, startup cleanup followed lifecycle-aware shutdown rules, and saved models reloaded more predictably.

Linux support became much more concrete in the second half of the week. Portable test paths, path-casing fixes, build-system adjustments, and warning fixes landed alongside a new Ubuntu CI workflow that exercised GCC, Clang, optional modules, the full kernel suite, WebUI checks, and browser regressions. Installation guides for Linux, macOS, and Raspberry Pi were expanded in the same window, so the repository ended the week with a clearer cross-platform story in both automation and documentation.

The closing stretch combined numerical hardening with structural cleanup. Randomized modules adopted module-owned state and reproducible seeds, angle and scalar math semantics were tightened, and modules such as `Normalize`, `Softmax`, `RegressionStatistics`, `RotationConverter`, and the Gaussian family received more explicit edge-case behavior. The last run of commits then separated kernel setup, execution, state persistence, WebUI data handling, and support types into their own translation units, leaving the codebase more testable and easier to navigate by the end of the week.
