## Development Notes

The week began with process and policy changes rather than new runtime features. Repository instructions were expanded so external libraries now require approval, new modules default toward native C++ implementations, kernel changes stay outside ordinary module work unless explicitly approved, and security-reducing changes require direct review. That gave the repository a clearer operating contract before the larger implementation work landed.

Most of the week then centered on template matching. Early commits introduced learned features, projective overlay rendering, and support for local Python interpreters, but the larger direction quickly became a native boundary: model artifacts gained a verified contract, ONNX inference moved behind an explicit checked interface, ALIKED features and LightGlue correspondences flowed through native matrices, and the old Python template-matching runtime was removed. By the end of that push, the matcher had become a native pipeline rather than a Python-hosted one with native attachments.

The remainder of the template-matching series focused on making that new path behave consistently during live use. Verification stayed inside the intended learning region, matched and learned features received clearer overlays, tracking polygons remained visible and closed, and reacquisition rules were tuned to tolerate motion while still rejecting weak or inconsistent matches. Several commits adjusted how many feature matches were accepted, how the learning window was sized, and how Lucas-Kanade tracking predicted motion, so the week reads as a sustained effort to make the learned matcher dependable rather than merely functional.

The closing changes were smaller but still concrete. Output sizing was corrected so indexed aliases survived setup correctly, `RingWorld` appeared in an initial commit and then an update pass, and HTTP connection resets were downgraded from warning-level noise to quieter logging. By Sunday, Ikaros ended the week with a more native template-matching stack, clearer repository guardrails, and the start of another simulation module.
