## Development Notes

Work recorded under `ikaros-project` shifted the CVAE documentation toward an explicit account of the module's available behavior. The expanded reference explained how configuration choices affect representations, losses, and updates, including gate scheduling and the differences between gradient-based and vector-quantization prototype updates. These were documentation changes to existing behavior, rather than new training mechanisms.

The hierarchy section made the connections between modules concrete. Lower-level latent means feed the upper encoder, while the upper decoder's output supplies delayed feedback in the lower level's latent coordinates. The documentation covered fixed shapes, dense-latent reshaping, suitable losses for continuous upper-level inputs, and the latency introduced by feedback. It also clarified that each module trains locally: top-down decoding does not propagate gradients across connections or perform joint hierarchical posterior inference. A hierarchy diagram, with Mermaid source and an SVG rendering, accompanied the explanation.

Repository cleanup removed the experiment scripts and models used for MNIST comparisons and moving-blob hierarchy studies, together with generated evaluation plots. A separate commit removed five remaining reports covering dense VAE comparisons, direct VAE sweeps, downsampled five-layer models, parameter sweeps, and SOM-VAE experiments. Their removal changed what was available in the checkout; it did not introduce new experimental results. The week's opening devlog commit recorded the preceding week's work, which remains covered by its own entry.
